# summative-HTML-CSS-Personal-website-


This is my response to the summative lab part 2 building a personal website using HTML and CSS

## Instruction

After completing the calculator project, you want to showcase your work to the world. You’ll create a personal website that highlights your skills and projects, providing a platform for others to learn more about you as a developer.

You will need to create an HTML page that will serve as a personal website. Your goal in this lab is to:

- Build a multi-section website using HTML
- Style the website using CSS to improve aesthetics
- Include information about you, your skills, and your projects

## Define the Problem

You need to create a personal website that includes:

- A header with your name and a link to your GitHub profile.
- An “About Me” section with a brief bio and your skills.
- A “Projects” section showcasing at least two projects.
- CSS styling to enhance the website’s appearance.

## Determine the Design 

Header 

Add important information as a header on top of the page
Include your name
Include a link to your github profile
Organize content into clearly defined sections

About Me section

Showcase yourself, adding a brief but compelling overview of who you are
Include a section about what skills you have. Make sure to include the languages you have learned!

Projects Showcase

Showcase the calculator project you have created
- Include name of project
- Include image of project
- Include description of project
Showcase an additional project based on any previous course labs or personal projects

CSS styling 

- Center the header content
- Turn the projects section into a grid
- Choose a background color and consistent color scheme

Develop Code

Develop your code and script to match the design. Your script should adhere to the following: 

- Readability: Readability of the code
- HTML: Proper use of various html tags
- CSS Format: Add CSS formatting to correct html tags
- Coding Best Practices: Adherence to HTML/CSS coding conventions and best practices

Test and Refine

- View the website: Open HTML often to see how page looks
- Check Responsiveness: Verify that HTML/CSS is displaying as wanted.
- Refine Design: Make any necessary adjustments to the code blocks to achieve the desired look.


Document and maintain 

- Version Control: Use version control to track changes. This allows for easy updates, collaborative editing, and the ability to revert to previous versions if necessary.
- Regular Updates and Reviews: Schedule regular reviews and updates for code to ensure content remains relevant, accurate, and aligned with the latest coding developments and industry practices.
- Documentation and Examples Repository: Maintain a centralized repository containing all lab documents, example code, and solutions.
